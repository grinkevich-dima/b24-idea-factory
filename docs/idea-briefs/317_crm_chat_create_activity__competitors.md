# Идея 317 — конкуренты

## Поисковые формулировки
- дело из чата сделки
- создать дело из чата CRM
- follow-up из чата Bitrix24
- сделка из чата одним кликом
- активность из IM CRM
- todo из чата сделки
- напоминание из чата CRM

## Матрица (6)

### 1) «Сделка из чата: одним кликом» (Консалт-Инфо)
- **Job:** сообщение → создать *сделку*
- **Дыра:** другой объект; не закрывает «дело себе на уже существующую сделку»

### 2) Штатный таймлайн сделки
- **Job:** создать дело из карточки
- **Дыра:** нужно уйти из чата в карточку; жест «из чата» нет

### 3) Роботы CRM / БП
- **Job:** при событии создать дело
- **Дыра:** нет человеческого выбора в момент договорённости в чате; шум и ложные срабатывания

### 4) Приложения «напоминание по сообщению» / отложить сообщение
- **Job:** личное напоминание по тексту IM
- **Дыра:** часто без привязки к сделке как OWNER CRM‑дела

### 5) Интеграции ОЛ / внешние чаты (Jivo и аналоги)
- **Job:** внешний чат → лид/сделка
- **Дыра:** внешняя интеграция (вне scope); не внутренний чат сделки

### 6) Универсальные todo REST без продукта
- API `crm.activity.todo.add` есть, готового killer‑UI «из чата сделки» в Маркете как массового стандарта нет

## Вывод
Клин: **чат сделки → дело на себя с OWNER=сделка**, без создания новой сделки и без авторобота по каждому сообщению.
