# Идея 317 — УТП, MVP, релиз, Маркет

## УТП
Из чата сделки CRM создаёте дело **на себя** с привязкой к этой сделке — follow‑up не теряется после переписки с коллегой.

## MVP
1. Кнопка в чате сделки
2. Пресеты даты/типа дела
3. Создание дела на текущего пользователя + связь со сделкой
4. Подтверждение / ссылка на дело

## Не‑MVP
- Разбор текста сообщений / AI
- Создание сделки из сообщения (другой продукт)
- Автосоздание дел роботом без клика
- Эскалации РОПу

## Релиз 1–2 недели
### Неделя 1
- Placement + определение сделки из контекста чата
- Мастер пресетов + `crm.activity.todo.add`
- Права: crm (запись дел), минимум IM

### Неделя 2
- Пресеты заголовков, пустые состояния, ссылка обратно в чат
- Тесты на чат без привязки к CRM (hide button)
- Текст Маркета + FAQ по правам

## Метрики
- Число дел, созданных из чата / неделю
- Доля пользователей, создавших ≥1 дело за 7 дней после установки
- TTV ≤ 2 минут

## Риски
- Чаты без CRM‑привязки → не показывать кнопку
- Путаница с «сделка из чата» → в названии явно «дело себе»

## Текст Маркета (черновик)
**Заголовок:** Из чата сделки — дело себе  
**Подзаголовок:** Один клик: дело на вас с привязкой к сделке, чтобы не забыть перезвонить.  
**Кому:** менеджерам и аккаунтам, которые живут в чатах сделок.  
**Как:** открыли чат сделки → «Создать дело» → выбрали «завтра 11:00» → готово.
