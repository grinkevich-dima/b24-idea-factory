# Идея 317 — скрины, безопасность, FAQ

## Скриншоты (6)
1. Чаты сделки: кнопка «Создать дело себе»
2. Мастер: тип + пресет времени
3. Подтверждение: дело создано + ссылка
4. Таймлайн сделки: новое дело от текущего пользователя
5. Пустое состояние: чат без привязки к сделке (кнопки нет / пояснение)
6. Настройки: пресеты заголовков (опц.)

## Права (минимум)
- CRM: создание дел по доступным сделкам
- Пользователи: текущий user id
- IM: контекст чата (без хранения текста переписки)

## Не делаем
- Не читаем и не храним тексты сообщений чата
- Не пишем в чужие сделки вне прав пользователя
- Не создаём сделки/лиды из сообщений в этом MVP

## FAQ
**Это не „сделка из чата“?** Нет. Создаётся дело на уже связанную сделку, ответственный — вы.  
**Нужен ли робот?** Нет, только ваш клик.  
**Видит ли приложение переписку?** Нет, только факт чата и id сделки.  
**Сколько до пользы?** Сразу после установки — откройте чат сделки и создайте дело.
