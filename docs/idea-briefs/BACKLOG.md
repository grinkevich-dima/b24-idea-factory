# Беклог идей

Сюда попадают идеи по команде `в беклог N` (сквозная нумерация).

Формат строки:

`- [ ] **NN** — Название (Домен) — коротко почему в беклог`

## Очередь

- [ ] **49** — Напоминания по выбранным сообщениям (Чаты) — важное сообщение теряется в ленте; MVP: «напомнить позже» + личный список

### 49 — Напоминания по выбранным сообщениям
- **Домен:** Чаты
- **ICP:** любой сотрудник
- **Боль:** важное сообщение теряется в ленте
- **Эффект:** меньше забытых договорённостей
- **MVP:** «напомнить позже» из сообщения, личный список напоминаний
- **Риск:** дублирование штатных напоминаний
- **Скоринг:** A4 / B4 / C5
- **Источник:** `PROPOSED.md`
