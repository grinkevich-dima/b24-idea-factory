### 44 — Чаты без владельца
- **Домен:** Чаты
- **ICP:** руководитель поддержки / админ портала
- **Боль:** непонятно, кто отвечает за чат, сообщения «висят»
- **Эффект:** меньше чатов без ответственного
- **MVP:** список чатов без владельца, назначение владельца, дайджест руководителю
- **Риск:** не везде есть сущность владельца — нужна настройка
- **Скоринг:** A4 / B4 / C4
- **Источник:** `PROPOSED.md`

### 45 — Контроль повторных касаний по сделке

- **MVP:** правила «мин/макс дней между активностями», список нарушений, алерт

### 109 — Детектор проскока стадий сделки
- **Домен:** CRM
- **API‑угол:** B (история стадий) — `crm.stagehistory` / события смены стадии
- **Placement:** пункт в меню CRM + детализация из карточки сделки
- **Механика:** сравнивать фактическую последовательность стадий с разрешённым графом воронки; ловить пропуски и сверхбыстрые переходы
- **ICP:** РОП, владелец CRM‑регламента
- **Боль:** менеджеры перескакивают обязательные этапы, регламент формально «есть», по факту нет
- **Эффект:** меньше нарушений процесса; прозрачный список аномальных переходов
- **MVP:** граф допустимых переходов по воронке, журнал нарушений, дайджест РОПу, ссылка на сделку
- **Риск:** у клиентов разные воронки — настройка графа обязательна; не путать с легитимными админ‑переносами
- **Скоринг:** A5 / B4 / C3
- **Источник:** `PROPOSED.md`

### 167 — Сохранить решение из чата задачи в реестр
- **Домен:** Чаты / Задачи
- **Пометка:** доработать логику
- **ICP:** тимлид, руководитель проекта, постановщик
- **Боль:** итог обсуждения тонет в чате задачи — через месяц снова спорят и переделывают
- **Эффект:** меньше повторных обсуждений, быстрее онбординг нового исполнителя
- **MVP:** форма «решение», привязка к задаче/проекту, поиск по реестру, без NLP и без копирования всей переписки
- **Чем НЕ штатный облачный B24:** чат задачи и результат задачи не заменяют реестр решений со ссылками и поиском по проекту
- **Риск:** дисциплина ручной метки — напоминание при закрытии задачи «было ли решение?»
- **Скоринг:** A4 / B4 / C4
- **Источник:** `PROPOSED.md`

### 176 — Кто из команды чаще двигает сроки, а кто закрывает в срок

- **Чем НЕ штатный облачный B24:** список перенесённых возможен фильтром; профиля дисциплины сроков нет
- **Риск:** перенос по вине заказчика — мягкая интерпретация инициатора сдвига
