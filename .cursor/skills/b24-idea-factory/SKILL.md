# Bitrix24 Idea Factory (конвейер ≤5 часов на 1 приложение)

## Ограничения (обязательные)
- Приложения: **публичные** для **Bitrix24 Marketplace**
- Платформа: **только облако Bitrix24** (не коробочные/онпрем‑специфичные возможности)
- Домены: **CRM**, **Задачи/Проекты**, **Аналитика/Отчёты**, **Чаты**
- Исключить: **внешние интеграции**, **отраслевые решения**
- Язык артефактов: **русский**
- Метод: [`docs/idea-briefs/IDEA_METHOD.md`](../../docs/idea-briefs/IDEA_METHOD.md) — схема **G1→G5**
- Почасовую автогенерацию **не включать**, пока пользователь явно не попросит

## Схема в двух словах

1. **G1** Генерация: роль + ритуал → job → клин (1–2 кандидата).
2. **G2** Самоотсев по чеклисту (молча выкинуть слабое).
3. **G3** Тяжёлая валидация **до чата**: скоринг + штатив + 5–10 конкурентов Маркета.
4. **G4** Предложение в чат. В `PROPOSED` **не писать**, пока нет ответа.
5. **G5** После `ок N` / `в беклог N` — репо; полный пакет из 4 файлов — после `в беклог N`.

Команды человека: `ок N` · `в беклог N` · `отклони N` · `доработай N: …`

## Выходные артефакты
Папка: `docs/idea-briefs/`

- `INDEX.md` — индекс пакетов
- `PROPOSED.md` — журнал **только после** `ок` / `в беклог`
- `BACKLOG.md` — после `в беклог N`
- `IDEA_METHOD.md` — схема и анти‑паттерны

Пакет по идее `NN` (после беклога):
- `NN_<slug>.md`
- `NN_<slug>__competitors.md`
- `NN_<slug>__mvp_release_market.md`
- `NN_<slug>__screens_security_faq.md`

## Конвейер агента

### G1 — Генерация (от недоделки штатива)
- Сначала **G0** в `IDEA_METHOD.md`: helpdesk + семья фич + сигнал Маркета → таблица «есть → обрыв → ставка → клин».
- Затем job + клин, который **добивает обрыв**, не придумывает новую привычку.
- По умолчанию **1–2** кандидата после G2/G3.
- ICP: продажи / маркетинг / аккаунт / поддержка / РОП. Не IT‑WIP.

### G2 — Самоотсев (дисквал = не показывать)

1. Робот/БП 1:1?
2. Штатный дедуп?
3. Голый period KPI / типовой отчёт без новой работы?
4. Пустое поле → алерт?
5. «Нет следующего дела» / дайджест просрочек?
6. Фейковый chat handoff / чтение текста чатов?
7. TTV > 10 минут?
8. IT‑продуктивность без покупателя вне IT?
9. Мельница детекторов (серии/path/fingerprint/коллизия без действия системы)?
10. Платёжный тест провален / клон последних сюжетов / боль надуманная?
11. **Дисциплинозависимость:** без ежедневного ручного ввода польза = 0? (закрепы, теги, брифы, реестры) — нужен автопилот рутины из уже существующих данных CRM
12. **Гигиена CRM:** чинит даты/дела/слоты/строки без ставки денег/плана/крупного слива/войны отделов?

Уроки: **114–118**, **269–273**, **285/286/288**, радары **274–313**, дисциплина **314–318**, авто‑гигиена **314–318b**.

### G3 — Тяжёлая валидация (до чата)
- Доказательство недоделки штатива (helpdesk/экран: что есть / где обрыв).
- Скоринг A/B/C (порог в чат: A≥4, B≥3, C≥3).
- Разбор: робот/БП 1:1? Маркет 5–10 конкурентов.
- Красные флаги реализации из IDEA_METHOD.

Провал G3 → не предлагать в чат.

### G4 — Предложение в чат
Формат: название → сцена/боль → что делает → для кого → эффект → MVP → зазор → как обходят → **валидация (A/B/C + конкуренты/дыры)** → риски → команды.

**Запрет:** `git commit` карточки идеи и файлов пакета **до** `ок` / `в беклог`.

### G5 — После согласия
- `ок N` → только `PROPOSED.md` + ротация ритуалов + commit/push.
- `в беклог N` → PROPOSED + BACKLOG + 4 файла пакета (шаги ниже) + INDEX + commit/push.
- `отклони N` → не писать идею; строка-урок в ротацию.

### После `в беклог` — полный пакет (≤5 часов)

**Конкуренты** — оформить черновик G3 в `__competitors.md` (дополнить при необходимости).

**УТП + MVP + релиз + текст Маркета** → `__mvp_release_market.md`:
- УТП с отличием от штатива
- MVP 3–5 фич, Не‑MVP
- Неделя 1 / Неделя 2
- метрики, риски
- текст Маркета

**Скриншоты + безопасность + FAQ** → `__screens_security_faq.md`:
- 6–8 скриншотов
- минимальные права, что не читаем/не храним
- FAQ для Маркета

**Корневой** `NN_<slug>.md` — ICP, боль, УТП, суть продукта.

## Правила качества
- Один killer‑экран в MVP, не комбайн.
- Польза ≤ 10 минут после установки.
- Не предлагать то, что режется фразой «это же стандартный Bitrix24» или «это робот/БП».
- Лучше 1 сильная идея, чем 5 средних.
